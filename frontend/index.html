Integration guide

The frontend sends these requests. Each endpoint should return JSON.

Text 
POST {base}/api/analyze/text
Content-Type: application/json
{ "text": "...", "language": "auto", "mode": "document" }
Voice 
POST {base}/api/analyze/voice
Content-Type: multipart/form-data
audio = <file>
Face 
POST {base}/api/analyze/face
Content-Type: multipart/form-data
image = <file>

Enable CORS on the Python server for the address you open this page from. Customize how results are drawn in renderResult() inside script.js.
